# 批量与文件夹转写导出

最后更新：2026-07-29（Asia/Shanghai）

## 版本

- 目标版本：`v0.12.0-rc.9`
- 实现分支：`codex/batch-transcript-folder-export`
- 基线提交：`493c17a`

## 已实现范围

- 媒体库多选后批量导出关联的转写记录。
- 文件夹右键菜单支持递归导出当前文件夹。
- 媒体库页头支持导出全部转写。
- 支持 TXT 和 Markdown，每条转写生成独立文件。
- 文件夹导出可选择是否包含子文件夹、是否保留文件夹结构。
- 媒体关联转写与纯文字历史转写统一解析并按转写 ID 去重。
- 未转写媒体、缺失记录和单文件写入错误分别汇总，不中断其他文件。
- Windows 非法字符、保留名称、同名文件及同名导出目录安全避让。
- 文件写入使用排他创建，不覆盖目标目录中的已有内容。
- 导出完成后可直接打开导出目录。

## 数据边界

- 渲染进程只提交转写 ID 或文件夹范围，不通过 IPC 批量传输正文。
- 主进程从 `TranscriptStore` 读取导出时的最新持久化版本。
- 文件夹范围以导出确认时的最新媒体库与历史索引为准。
- 所有文件夹段均经过安全归一化，最终路径必须位于本次导出根目录内。
